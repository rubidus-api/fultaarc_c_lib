# cab.txt - Microsoft Cabinet (.cab) fixtures made by tests/tools/cabmake.py and VALIDATED BY `7z x`/`7z t` (an
# independent CAB reader) before commit; see docs/research/formats/cab.md and T022. The listing is exact (every
# file our reader produces is here) and file content (size+crc32) is 7z-validated end to end - CAB is, with tar/ar/
# cpio/ISO, a fully 7z-validated container (no reader-defined divergence). basic.cab exercises an MSZIP folder (a
# file spanning several CFDATA blocks, so the cross-block window is used; a backslash subdir path; a UTF-8 name)
# AND a Store folder in the same cabinet (so uoffFolderStart slicing and the per-folder cache are pinned).
# reserve.cab sets cfhdrRESERVE_PRESENT (per-header/folder/datablock reserve) so the reserve-skip + the
# reserve-inclusive CFDATA checksum are exercised. The lzx*.cab fixtures exercise the LZX decoder (src/codec/lzx.c):
# lzx.cab a verbatim block with several files (uoffFolderStart slicing, a subdir path, a UTF-8 name);
# lzxaligned.cab an aligned-offset block (the aligned tree + split footer); lzxbig.cab a multi-chunk folder (the LZX
# block/window/R state spanning CFDATA boundaries, window 2^21); lzxe8.cab E8 x86 call-translation (7z reverses it
# too); lzx19.cab tree lengths with long equal runs (pretree code 19, the same-delta run). All are LZX-encoded by
# tests/tools/cabmake.py and validated by `7z x` (which reads CAB-LZX). quantum10/12/21.cab are QUANTUM folders (window
# 2^10, 2^12, 2^21) made by Microsoft's own Diamond 1.00.0530 tool from neutral plaintext (fixtures/cab/quantum-plain/:
# generated text, 40 000 random bytes spanning CFDATAs, a zero run) and validated by Windows' extrac32 (SHA-256 of every
# extracted file; the sibling clean room's record Q0051); quantum12.cab also carries a Store folder. 7z is not used on
# Quantum (its decoder is copyleft-derived; the clean room never ran it on type-2 data). Cross-cabinet files -> test_cab.c
# (UNSUPPORTED without a volume resolver) unless the set is opened by file: qset1/2/3.cab (Quantum, Diamond), mset1/2/3.cab
# (MSZIP, makecab) and lset1/2/3.cab (LZX, makecab) are 40 KiB cabinet sets from the same four neutral plaintexts
# (fixtures/cab/set-plain/): beta.bin is split across cabinets 1-2 (a CFDATA split at the boundary), gamma.txt/delta.bin
# sit in a folder continued from cabinet 2 into 3; validated by Windows' extrac32 per cabinet. Opened from ANY cabinet
# of a set the whole set lists and extracts the same four files (the PREV and NEXT chains are followed by name in the
# same directory), so each set has rows for all three of its cabinets.
# lzx21_makecab.cab (2026-11-12, D-044) is Windows makecab's own LZX at its largest window (/D CompressionType=LZX
# /D CompressionMemory=21, Windows 11): neutral generated plaintext (text, x86-like E8 calls, random, a 600 KB block
# repeated 1.1 MB later), 98 CFDATAs, E8 translation on; validated by Windows' extrac32 (SHA-256) and `7z t`. Its
# chunks end with a code shorter than the decoder's 10-bit look-ahead, which the reader once took for a cut-short
# chunk (every file failed).
