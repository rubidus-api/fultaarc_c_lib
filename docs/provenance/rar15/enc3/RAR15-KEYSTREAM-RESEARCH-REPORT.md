## 2. Mathematical Specification & C99 Implementation Walkthrough

### 2.1 Reflected IEEE 802.3 CRC-32 Primitive

Let $\mathbb{Z}_{2^{16}} = \{0, 1, \dots, 65535\}$ and $\mathbb{Z}_{2^{32}} = \{0, \dots, 2^{32}-1\}$, with bitwise XOR $\oplus$, unsigned right/left logical bit shifts $\gg, \ll$, and 16-bit cyclic rotations:

$$\text{rol}_{16}(x, r) = \bigl((x \ll r') \mathbin{\&} \texttt{0xFFFF}\bigr) \mid (x \gg (16 - r')), \qquad \text{ror}_{16}(x, r) = \bigl((x \gg r') \mid (x \ll (16 - r'))\bigr) \mathbin{\&} \texttt{0xFFFF}$$

where $r' = r \bmod 16$. Define the standard IEEE 802.3 reflected CRC-32 lookup table $T_{\text{ref}} : \{0, \dots, 255\} \to \mathbb{Z}_{2^{32}}$ generated from polynomial $P_{\text{CRC32}}(x) = x^{32} + x^{26} + x^{23} + x^{22} + x^{16} + x^{12} + x^{11} + x^{10} + x^8 + x^7 + x^5 + x^4 + x^2 + x + 1$ (reflected constant $\texttt{0xEDB88320}$):

$$T_{\text{ref}}[u] = \mathcal{F}^8(u), \qquad \mathcal{F}(x) = \begin{cases} \texttt{0xEDB88320} \oplus (x \gg 1) & \text{if } x \bmod 2 = 1, \\ x \gg 1 & \text{if } x \bmod 2 = 0. \end{cases}$$

Split each 32-bit word into its low and high 16-bit halves:

$$T_{\text{LO}}[u] = T_{\text{ref}}[u] \mathbin{\&} \texttt{0xFFFF}, \qquad T_{\text{HI}}[u] = T_{\text{ref}}[u] \gg 16.$$

### 2.2 Key Schedule (`pw` $\mapsto$ Initial 5-Word State)

Given a NUL-terminated raw byte string $P$, truncate to at most $77$ unsigned octets $e = (c_0, c_1, \dots, c_{N-1}) \in \{0,\dots,255\}^N$ with $N = \min(|P|, 77)$ and $c_j \in \{1,\dots,255\}$ (bytes are promoted as unsigned `uint8_t`, never signed `int8_t`). Starting from $R^{(0)} = \texttt{0xFFFFFFFF}$, $H^{(0)} = \texttt{0x0000}$, and $S_0^{(0)} = \texttt{0xFFFF}$, iterate for $j = 0, \dots, N-1$:

$$R^{(j+1)} = \bigl(R^{(j)} \gg 8\bigr) \oplus T_{\text{ref}}\!\left[(R^{(j)} \oplus c_j) \mathbin{\&} \texttt{0xFF}\right]$$

$$H^{(j+1)} = \bigl(H^{(j)} + T_{\text{HI}}[c_j] + c_j\bigr) \bmod 2^{16}$$

$$S_0^{(j+1)} = S_0^{(j)} \oplus \bigl(T_{\text{LO}}[c_j] \oplus c_j\bigr).$$

Setting $R = R^{(N)}$ (the unfinalized IEEE 802.3 CRC-32 $\text{CRC32}(e) \oplus \texttt{0xFFFFFFFF}$), $H = H^{(N)}$, and $b_x = \bigoplus_{j=0}^{N-1} c_j$, note that $S_0 = S_0^{(N)}$ collapses purely as an XOR function of $b_x$:

$$S_0(b_x) = \texttt{0xFFFF} \oplus T_{\text{LO}}[b_x] \oplus b_x \qquad \Bigl(\text{because } \bigoplus_{j=0}^{N-1} T_{\text{LO}}[c_j] = T_{\text{LO}}\!\left[\bigoplus_{j=0}^{N-1} c_j\right]\Bigr).$$

The **5-word live working state** $(W, M, K_2, H_r, S) \in (\mathbb{Z}_{2^{16}})^5$ ($80$ bits of mutable working state initialized from $\le 54$ effective key-schedule bits: $31$ active bits in $R \gg 1$, $16$ bits in $H$, and $7$--$8$ effective parity-coupled bits via $b_x$) is initialized as:

$$W_0 = R \mathbin{\&} \texttt{0xFFFF}, \qquad M_0 = \text{rol}_{16}(R \gg 16, 1), \qquad K_{2,0} = \texttt{0xFFFF}, \qquad H_{r,0} = H, \qquad S_0 = \texttt{0xFFFF} \oplus T_{\text{LO}}[b_x] \oplus b_x.$$

### 2.3 Per-Byte Stream Transition & Output

For each output byte index $i = 0, 1, 2, \dots$:

$$W'_i = (W_i + \texttt{0x1234}) \bmod 2^{16}$$

$$u_i = (W'_i \gg 1) \mathbin{\&} \texttt{0xFF}, \qquad t_i = T_{\text{ref}}[u_i]$$

$$S_{i+1} = (S_i + (t_i \gg 16)) \bmod 2^{16}$$

$$M_{i+1} = \text{ror}_{16}(M_i, 2) \oplus \text{ror}_{16}(t_i \mathbin{\&} \texttt{0xFFFF}, 1)$$

$$K_{2,i+1} = K_{2,i} \oplus M_{i+1}$$

$$H_{r,i+1} = \text{ror}_{16}(H_{r,i}, 2)$$

$$W_{i+1} = W'_i \oplus S_{i+1} \oplus H_{r,i+1} \oplus K_{2,i+1}$$

$$k_i = (W_{i+1} \gg 8) \mathbin{\&} \texttt{0xFF}.$$

Notice a classic structural artifact on step $i = 0$ versus $i \ge 1$: because $M_0 = \text{rol}_{16}(R_{\text{HI}}, 1)$, applying $\text{ror}_{16}(M_0, 2)$ computes $\text{ror}_{16}(R_{\text{HI}}, 1)$ on step $0$, and subsequently steps $M$ by $\text{ror}_{16}(\cdot, 2)$ for all $i \ge 1$. Store-mode and compressed payloads alike satisfy `stored[i] = plaintext_or_packed[i] ^ k_i` after decryption.
